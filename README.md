# Cosmic Overflow

We can do everything if we want!

## 项目信息

- Mod ID: `cosmic_overflow`
- Minecraft: `1.21.1`
- 构建插件: `ModDevGradle`
- Java: `21`
- 许可证: `GPL-3.0`

## 构建

    ./gradlew build

Windows 使用：

    gradlew.bat build

构建产物位于 `build/libs/`。

## 运行

    ./gradlew runClient
    ./gradlew runServer
    ./gradlew runData

首次启动需要下载 Gradle、NeoForge 与 Minecraft 依赖。
